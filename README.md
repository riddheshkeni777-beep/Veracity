# Veracity
Veracity is a modern AI-powered misinformation detection interface designed to analyze digital content and determine its credibility in real time. It provides a clean, institutional-grade dashboard for verifying claims, detecting fake news, and understanding information reliability.

---

## 🚀 Features

- 🔍 **AI-Powered Analysis Dashboard**
  - Submit text, headlines, or claims for verification
  - Real-time credibility scoring system

- 🖼️ **Multimodal Input Support**
  - Upload images along with text for deeper analysis

- 📊 **Credibility Scoring System**
  - Categorizes results into:
    - TRUE
    - FAKE
    - MISLEADING

- 📈 **Verification History**
  - Track previously analyzed cases within the session

- 🧠 **Modern UI/UX**
  - Built with Tailwind CSS
  - Glassmorphism design
  - Smooth animations and transitions

- 🌙 **Dark Mode Support**
  - Toggle between light and dark themes

- 🔔 **Notification System**
  - Real-time alerts and system status updates
